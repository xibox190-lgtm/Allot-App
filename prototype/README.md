# AI 导入计划原型

只体验「输入 → 计划草稿 → 继续调整 / 手动微调 → 使用计划」，不实现 Allot 其他模块。

在项目根目录运行 `npm run prototype`，打开 <http://127.0.0.1:4173>。不需要安装依赖。执行 `npm test` 验证计划解析与金额校验。此目录为早期演示，当前 MVP 请参考根目录 README。

## 可以体验

- 点击「试试半年计划」，得到示例草稿。
- 粘贴 Markdown 表格，或添加 `.md` / `.txt` 文件后发送。表格第一列为「月份」，其他列为项目，可包含「合计」列；这是本地解析，表格外说明不会被理解。
- 按月查看，直接修改金额或调整开始月份；合计自动计算。
- 输入「黄金这个月改成 2000」体验继续对话。演示中的「这个月」指草稿第一个月，只支持这种指定格式；无法理解的表达不会修改草稿。
- 添加 PNG / JPEG / WebP 图片并预览；未接入 API，图片不会被识别，也不会悄悄用示例代替。
- 「使用计划」后才保存到当前浏览器，刷新可恢复。编辑草稿不会覆盖上次保存，需再次使用计划。

## 尚未接入

真实 AI、图片理解、任意自然语言整理与澄清。页面始终显示「本地演示 · 未接 API」。用户提供 API 后，在 `public/plan.mjs` 的 `requestPlan` 对应边界接入真实服务，再替换本地演示逻辑；尚未假定服务商或接口协议。

数据结构为标的名称数组 `assets` 和月度列表 `months`；月度项包含 `month`（YYYY-MM）与对应的 `amounts`（整数分）。模型输出需经过同样的校验后进入草稿，必须由用户确认才导入。

此版本不包含安卓安装包、本月首页、买入记录和备份功能。浏览器保存仅用于体验，不是正式数据备份。
