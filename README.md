# Allot

把投资安排整理成计划，把每次买入记下来。

Allot 是一个以月度进度为核心的个人投资计划与买入记录工具。打开后，你可以看到本月各标的计划投入多少、已经投入多少，以及剩余安排。它适合已经有自己的投资安排、希望持续跟进执行情况的人。

采用深色界面，面向 Android 手机使用。数据保存在本地；AI 功能由你自行配置的模型服务提供。

## 可以做什么

- **整理计划**：把文字、Markdown / TXT 或图片交给 AI，整理成待确认草稿。
- **跟进本月**：查看各标的计划金额、已投金额和完成进度，左右切换月份。
- **记一笔**：记录每次买入，支持分次与超额投入，确认后才累计。
- **调整安排**：手动或通过 AI 修改计划，保留已有买入记录。
- **查看与整理记录**：通过投资日历查看每日买入，使用 AI 整理、修正历史记录。
- **导出文本**：复制已保存的计划和买入记录，便于查看和分析。

计划变更和 AI 整理出的记录都需要用户确认。Allot 不连接券商、不执行交易，也不提供收益预测或投资推荐。

## 下载与使用

**[下载 APK（v0.1.0 预览版）](https://github.com/xibox190-lgtm/Allot-App/releases/tag/v0.1.0)** · [查看全部版本](https://github.com/xibox190-lgtm/Allot-App/releases)

支持 Android 8.0+，需要具备现代网页能力的 Android System WebView。

1. 从发布页下载 `Allot-*.apk` 并安装；系统可能要求允许当前来源安装应用。
2. 在右上角菜单进入「设置」，填写模型服务的接口地址、模型名称及自己的 API Key。
3. 从「制定计划」开始，把已有安排交给 AI 整理，核对草稿后确认。
4. 每次买入后「记一笔」，在首页与日历查看执行情况。

手机直接请求你配置的模型服务，无需电脑或自建服务器。当前默认接口为 DeepSeek，模型名称请以服务商实际支持的名称为准。其他兼容接口的工具调用、图片和模型参数支持需要自行验证。API 调用可能产生服务商费用。

公开版使用独立发布签名和应用 ID，可与个人开发版共存；两者数据独立，不会自动迁移。后续版本保持相同发布签名时可直接覆盖升级。

## 数据与隐私

- Android 数据和 Key 保存在应用私有空间。目前没有额外的应用层加密。
- 使用 AI 时，对话、所选附件及模型通过工具查询到的计划、记录会发送至你配置的模型服务。AI 功能需要联网。
- 没有云同步。卸载应用或清空数据可能导致本地内容丢失。
- 文本导出不包含 Key 和聊天内容，但不是完整备份，目前没有对应的一键恢复功能。

详见 [数据与隐私说明](docs/PRIVACY.md)。请勿在 Issue、截图或日志中公开真实投资记录和 API Key。

## 当前状态

项目处于早期阶段，由个人按精力维护。核心计划、记录、日历和 AI 整理流程已实现；语音输入、历史统计、完整备份恢复和跨设备同步尚未提供。

示例和测试中的金额、标的用于说明功能，不构成投资建议。使用 AI 结果前请核对日期、金额与标的，重要记录请另行留存。
