# 数据与隐私

Allot 当前没有账号系统、开发者运营的数据服务器或内置遥测上报。源码和安装包不应包含使用者的真实数据或密钥。

## 本地保存

| 环境 | 计划、记录和对话 | 接口与 API Key |
| --- | --- | --- |
| 本地浏览器 | 当前地址的 localStorage（`allot.state.v1`） | 服务端 `.allot/config.json`，可用 `ALLOT_CONFIG_DIR` 改目录 |
| Android | 应用私有 SharedPreferences | 应用私有 SharedPreferences |

这些数据目前没有额外的应用层加密。本机其他有相应权限的程序、浏览器扩展、被入侵设备等仍可能读取数据。不要把配置目录放入公开同步目录。

浏览器服务只监听 `127.0.0.1`，用于单人本机运行。它不是具备用户认证和租户隔离的公网服务，不应直接暴露到互联网。

## 模型服务

调用 AI 时，请求可能包含当前对话、所选文字和图片附件，以及工具调用获取的计划和买入记录。浏览器请求经本机服务转发；Android 直接请求模型服务。API Key 随请求用于服务商认证。

服务商如何保存、使用请求，取决于其条款和账户设置。请选用可信服务，避免输入身份证号、银行账号、密码等无关信息。

## 清理、导出与反馈

清空数据删除计划、记录、草稿和对话，保留 AI 配置与 Key；Key 需在「设置 → 管理 API Key」中单独清除。开启新对话保留已保存的计划与记录。

文本导出只包含已保存的计划或买入记录，不包含 Key、聊天和附件，也不提供完整恢复能力。卸载应用、清理浏览器存储或改变浏览器访问地址前，请留存重要记录。

提交问题时，用虚构标的和金额复现。不要发送完整配置、浏览器存储、手机备份或未脱敏的附件。
